# boxer extension for Gemini CLI

Generated by `boxer package gemini-cli` [[.Version]]. Do not edit; regenerate.

## Install

```sh
gemini extensions install ./gemini-cli
```

`boxer` must be on `PATH`; hooks call it by name.

## What the bundle does

| Component | File | Purpose |
| --- | --- | --- |
| Instruction | `GEMINI.md` (`contextFileName`) | Loaded as context for every session |
| Lifecycle hooks | `hooks/hooks.json` | `SessionStart` provisions and injects `additionalContext`; `SessionEnd` reclaims per `destroy_on` |
| Intercept hook | `BeforeTool` on `run_shell_command` | Mode `rewrite`: `hookSpecificOutput.tool_input.command`. Mode `tool`: top-level `decision: deny` |
| Run tool | `mcpServers.boxer` | `boxer_run`, `boxer_status` |
| Gap closer | `excludeTools: ["run_shell_command"]`[[if not .ToolMode]] (not rendered: mode = [[.Mode]])[[end]] | Removes the shell tool entirely in `tool` mode; the agent never forms the intent |

Mode at render time: `[[.Mode]]`.
