# boxer extension for pi

Generated by `boxer package pi` [[.Version]]. Do not edit; regenerate.

## Install

Copy into the repository root (`boxer install pi` does this):

- `works.earendil.pi/extensions/boxer.ts` → `.pi/extensions/boxer.ts` — project extension; pi loads it once the project is trusted. For an
  untrusted or one-off run: `pi -e .pi/extensions/boxer.ts`.
- `AGENTS.md` — append the section to your repository's `AGENTS.md`.

`boxer` must be on `PATH`; the extension calls it by name.
