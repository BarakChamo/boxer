# boxer plugin for Grok Build

Generated by `boxer package grok` [[.Version]]. Do not edit; regenerate.

## Install

Grok Build reads `.grok-plugin/plugin.json`, which points at `skills/`, `ai.x.grok/hooks/hooks.json`
and `mcp.json`. `grok plugin validate <dir>` checks it; add the directory through `grok plugin
install <dir>`, `/plugin`, or a marketplace entry.

`boxer` must be on `PATH`; hooks call it by name.

## What the bundle does

| Component | File | Purpose |
| --- | --- | --- |
| Instruction | `skills/boxer/SKILL.md` | Tells the agent how execution works here |
| Lifecycle hooks | `ai.x.grok/hooks/hooks.json` | `SessionStart`/`SubagentStart` provision and instruct; `SessionEnd`/`SubagentStop` reclaim per `destroy_on` |
| Intercept hook | `PreToolUse` on `Bash` | Mode `rewrite`: `hookSpecificOutput.updatedInput`. Mode `tool`: deny with the exact fix |
| Run tool | `mcp.json` | `boxer_run`, `boxer_status` |
| Gap closer | hook rewrite; PATH shims via `boxer shim install` | Grok Build exposes no per-agent tool restriction boxer could verify, so the rewrite hook is the closure |

The mode in force is a property of the checkout, not of this package: run `boxer brief` to see it.
