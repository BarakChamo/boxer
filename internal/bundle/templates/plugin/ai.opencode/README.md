# boxer plugin for OpenCode

Generated by `boxer package opencode` [[.Version]]. Do not edit; regenerate.

## Install

Copy into the repository root:

- `ai.opencode/plugins/boxer.ts` → `.opencode/plugins/boxer.ts`, loaded automatically from the project plugin directory.
- `ai.opencode/opencode.json` — merge the `mcp.boxer` entry into your existing config.
- `AGENTS.md` — append the section to your repository's `AGENTS.md`.

`boxer` must be on `PATH`; the plugin calls it by name.

## What the bundle does

| Component | File | Purpose |
| --- | --- | --- |
| Instruction | `AGENTS.md` | Tells the agent how execution works here |
| Lifecycle | `boxer.ts` `event` on `session.created` | Provisions per `create_on` |
| Intercept | `boxer.ts` `tool.execute.before` on `bash` | Mode `rewrite`: mutates `output.args.command`. Mode `tool`: throws with the exact fix |
| Run tool | `opencode.json` `mcp.boxer` | `boxer_run`, `boxer_status` |
| Gap closer | argument mutation; PATH shims via `boxer shim install` | |

Mode at render time: `[[.Mode]]`.
