# boxer plugin for OpenCode

Generated by `boxer package opencode` [[.Version]]. Do not edit; regenerate.

## Install

Copy into the repository root (`boxer install opencode` does all three):

- `ai.opencode/plugins/boxer.ts` to `.opencode/plugins/boxer.ts`. OpenCode loads it from the project plugin directory.
- The `mcp.boxer` entry of `ai.opencode/opencode.json`, merged into the repository's `opencode.json`.
- `AGENTS.md`, appended as a section to the repository's `AGENTS.md`.

`boxer` must be on `PATH`. The plugin calls it by name.

## What the bundle does

| Component | File | Purpose |
| --- | --- | --- |

| Intercept | `boxer.ts` `tool.execute.before` on `bash` | Mode `rewrite`: mutates `output.args.command`. Mode `tool`: throws with the exact fix |
| Run tool | `opencode.json` `mcp.boxer` | `boxer_run`, `boxer_status` |
| Gap closer | argument mutation; PATH shims via `boxer shim install` | |

The mode in force is a property of the checkout, not of this package: run `boxer brief` to see it.
