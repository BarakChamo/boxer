# boxer for DeepSeek Harness (dsh)

Generated by `boxer package dsh` [[.Version]]. Do not edit; regenerate.

## Status

DSH (`npx @deepseek-ai/dsh`) is "everything is a plugin"; hooks come from a hooks plugin
(`dsh-plugin-hooks` or `dsh-hooks-plugin`) that reads `.dsh/hooks.json` in the converged shape and
can only allow or block: exit 2 or a JSON `decision: "block"`. No input rewrite. This bundle relies
on PATH shims as the gap closer: with `enforcement = both` (default) the hook allows bare commands
because the shim already sandboxes them; with `enforcement = hook` it denies and names the exact
`boxer run` line. DSH is in developer preview; verify the plugin you install against this layout.

## Install

1. `boxer shim install`, then prepend the printed directory to `PATH` in the shell DSH launches.
2. `com.deepseek.dsh/hooks/hooks.json` → `.dsh/hooks.json` in the repository (`boxer install dsh` does this).
3. `mcp.json` → your DSH MCP configuration (path depends on the MCP plugin you use).
4. `skills/boxer/SKILL.md` → `.agents/skills/boxer/SKILL.md`.

`boxer` must be on `PATH`; hooks and shims call it by name.
