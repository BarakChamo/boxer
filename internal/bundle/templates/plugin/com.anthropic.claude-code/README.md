# boxer plugin for Claude Code

Generated by `boxer package claude-code` [[.Version]]. Do not edit; regenerate.

## Install

Write the files into the repository:

```sh
boxer install claude-code
```

That merges the hooks into `.claude/settings.json` and the run tool into `.mcp.json`, and copies
the skill to `.claude/skills/boxer/` and the agent to `.claude/agents/boxed.md`.
`boxer install claude-code --user` merges the hooks into `~/.claude/settings.json` instead.

Or load this directory as a plugin:

```sh
claude plugin install ./boxer   # the full package, or ./claude-code (this view)
claude --plugin-dir <dir>       # for one session
```

`.claude-plugin/plugin.json` points Claude Code at `skills/`, `com.anthropic.claude-code/hooks/hooks.json`
and `mcp.json`.

`boxer` must be on `PATH`. Hooks call it by name. Check with `boxer doctor`.

## What the bundle does

| Component | File | Purpose |
| --- | --- | --- |
| Instruction | `skills/boxer/SKILL.md` | Tells the agent how execution works here |
| Lifecycle hooks | `com.anthropic.claude-code/hooks/hooks.json` | `SessionStart`/`SubagentStart` provision and instruct; `SessionEnd`/`SubagentStop` reclaim per `destroy_on` |
| Intercept hook | same file, `PreToolUse` on `Bash` | Mode `rewrite`: rewrites intercepted commands to `boxer run`. Mode `tool`: denies with the exact fix |
| Run tool | `mcp.json` | `boxer_run`, `boxer_status` |
| Gap closer | PATH shims via `boxer shim install`; `agents/boxed.md` | A shim directory on PATH sandboxes a bare `npm`. The `boxed` agent has no Bash tool at all |

The mode in force is a property of the checkout, not of this package: run `boxer brief` to see it.
