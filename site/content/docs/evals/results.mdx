Everything here comes from the matrix tier. Nothing is listed as supported because the code
exists; it is listed because a cell ran and scored.

Latest runs, 2026-09-25, on the release binary: two full passes of the matrix — 55 cells, three at
a time, every cell on `zai/glm-5.3-flash` so the integration level is the only variable — one with
`[urls]` on and the address withheld from the prompt, one without as the control. The full
scorecards are `docs/eval-matrix-report.md` and `docs/eval-matrix-urls-report.md`.

The inside gap did not hold up for four of the five harnesses. Re-run in isolation, alternating the

Every level is carried by at least two harnesses, except shell substitution — OpenHands is the only
harness whose terminal shell is configurable, and a second witness would have to be invented rather
than found.

## When boxer only asks

Live, eight harnesses, four models each, with a prompt that never mentions boxer:

| scenario | result | notes |
| --- | --- | --- |
| `prep` — host-side setup, reached through the harness | **32 of 32** | every harness, every model; 8 of 8 on docker |
| `server` — find this worktree's dev server | **25 of 32** | 5 harnesses on all four models; Kimi and Copilot on two of four; Grok on one |

A harness is blamed only when every model fails it. Kimi and Copilot passing on two of four is
model adherence. Grok never shows boxer's brief to the model, which is a known harness fact rather
than a boxer defect; its cell is kept failing on purpose so the finding stays visible.

## Known limits

These are measured, not suspected.

**PATH shims do not survive a login shell.** A login shell rebuilds `PATH`; on macOS `path_helper`
puts the system directories first. A harness that runs commands through `zsh -lc` — Codex does —
reaches the host. boxer cannot out-rank `path_helper`, so `boxer doctor` detects the situation and
names the enforcement to use instead.

**Gemini CLI needs its own key.** It speaks only the Gemini API, which the AI Gateway does not
serve, so its cells skip rather than run.

**Conductor is verified by hand.** It is a native app rather than an Electron one, so there is no
debugging port to drive, and its CLI drives cloud workspaces where boxer has nothing to sandbox.

**fx is supported inside the guest only.** It has no hooks, its shell cannot be denied headlessly,
and it resolves commands past a PATH shim, so outside the guest there is nothing for boxer to hold
onto. Inside there is, and it passes — but it is the least stable inside harness measured: its
`add-a-page` cell lost its dev server in two of three runs with `[urls]` on and none of three
without, and an earlier run without URLs lost its `prove-and-install` server the same way. The
agent in those runs did not touch the server or the URL variables, so the cause is not established.

## Reading a run

Archived runs live in `docs/evals/matrix/`, newest first, with a JSON line per run for reading the
series by machine. A run is comparable with another only when the model, the concurrency and the
host match, which is why each report carries them.

Cells that fall short are worth reading rather than counting: the scorecard names which claim
failed, and the report keeps the transcript and the trace for each one.
