The latest [matrix tier](/docs/evals/matrix) ran two full passes of 55 cells on 2026-09-25. The
default pass scored 99.4% of weighted checks. The URLs-mode pass scored 98.7%.

| | default | URLs mode |
| --- | --- | --- |
| weighted checks | **99.4%** | **98.7%** |
| cells at 100% | 54 of 55 | 50 of 55 |
| cost | $1.89 | $3.04 |

The passes ran three cells at a time. Every cell used `zai/glm-5.3-flash`, so the integration level
is the only variable. Both passes used boxer v1.0.0-48-ged8def6 with uncommitted changes, smolvm
1.16.1 and `node:24-bookworm-slim`, on a 10-core, 24 GB Apple Silicon Mac. The URLs-mode pass had
`[urls]` on and kept the dev server's address out of the prompt. The default pass is the control.
Scorecards are in `docs/eval-matrix-report.md` and `docs/eval-matrix-urls-report.md`.

A harness counts as supported at an [integration level](/docs/setup/integration-levels) only if a cell
ran and scored there.

The inside gap in URLs mode came from a boxer bug unrelated to URLs. Caching a harness install as a
[pack](/docs/concepts/scopes-and-packs) stops the machine, and boxer did not restart the `start`
services afterwards. The bug showed only on a host's first round of inside cells, and the URLs-mode
pass ran first. After the fix, with the pack cache cleared, the inside cells ran cold once in each
mode. They passed 10 of 10 and 10 of 10.

Every level has at least two passing harnesses except shell substitution. OpenHands is the only
harness whose terminal shell is configurable.

## When boxer only asks

The adherence tier runs eight harnesses on four live models each, with a prompt that never
mentions boxer. The latest report is from 2026-09-25, in `docs/eval-adherence.md`.

| scenario | result | notes |
| --- | --- | --- |
| `prep`, host-side setup reached through the harness | **32 of 32** | every harness, every model; 8 of 8 on docker |
| `server`, find this worktree's dev server | **25 of 32** | 5 harnesses on all four models; Kimi and Copilot on two of four; Grok on one |

A harness is blamed only when every model fails it. Kimi and Copilot passed on two of four models,
so those failures count as model failures. [`prep`](/docs/configure/environment) is the opt-in
host-side step that runs before the sandbox starts. Grok never shows boxer's brief to the model. Its
cell fails.

## Known limits

**PATH shims fail under a login shell.** A login shell rebuilds `PATH`. On macOS,
`path_helper` puts the system directories first. A harness that runs commands through `zsh -lc`, as
Codex does, reaches the host. boxer cannot put its shims ahead of `path_helper`, so `boxer doctor`
detects this and names the enforcement to use instead.

**Gemini CLI needs its own key.** It supports only the Gemini API, which the AI Gateway does not
serve, so its cells are skipped.

**Conductor is verified by hand.** It is a native app, not an Electron app, so it has no
debugging port to drive. Its CLI drives cloud workspaces, where boxer has nothing to sandbox.

**fx is supported inside the guest only.** It has no hooks, its shell cannot be denied headlessly,
and it resolves commands past a PATH shim, so boxer has no way to intercept it from outside. Inside
the guest it passes.

## File watching

A dev server that reloads on save waits for inotify events. This run checked whether an edit made on
the host reaches a watcher in the sandbox. Each round made five in-place appends and five
write-then-rename saves to files under `src/`, one second apart. The watcher was chokidar 4 on
`node:24-alpine`. Measured on an M4 Mac on 2026-09-30.

| backend | rounds | edits seen, native events | edits seen, `CHOKIDAR_USEPOLLING=1` |
| --- | ---: | ---: | ---: |
| smolvm 1.16.1 | 3 | 30 of 30 | not needed |
| docker, OrbStack 29.4.0 | 2 | 20 of 20 | not needed |
| Apple `container` 1.4.1 | 2 | 0 of 20 | 20 of 20 |
| podman 5.8.2, `applehv` machine | 2 | 0 of 20 | 20 of 20 |

On Apple `container` and podman the watcher was running, and it saw an edit made inside the sandbox.
Only host edits were missing. On smolvm, a plain `fs.watch` sometimes reported an edit against the
directory rather than the file (2 of 5 in-place edits in one round). chokidar still named the file every
time. The smoke suite's `file watching` cells hold this table to the truth on every backend.

## Reading a run

Archived runs are in `docs/evals/matrix/`, newest first, with a JSON line per run. Two runs are
comparable only when the model, the concurrency and the host match. Each report records all three.

For a cell below 100%, the scorecard names the claim that failed, and the report keeps the cell's
transcript and trace.
