A harness is listed as supported at a level only if a cell ran and scored there. The level and
harness tables come from the [matrix tier](/docs/evals/matrix).

Conditions: 2026-09-25, release binary, two full matrix passes of 55 cells, three at a time, every
cell on `zai/glm-5.3-flash` so the integration level is the only variable. One pass had `[urls]` on
and the dev server's address withheld from the prompt (URLs mode); the other is the control
(default). Scorecards: `docs/eval-matrix-report.md` and `docs/eval-matrix-urls-report.md`.

The inside gap in URLs mode was a boxer bug unrelated to URLs: caching a harness install as a
[pack](/docs/concepts/scopes-and-packs) stops the machine, and boxer did not restart the `start`
services afterwards. It showed only on a host's first round of inside cells, and the URLs-mode pass
ran first. After the fix, with the pack cache cleared, the inside cells ran cold once in each mode:
10 of 10 and 10 of 10.

Every level has at least two passing harnesses except shell substitution: OpenHands is the only
harness whose terminal shell is configurable.

## When boxer only asks

The adherence tier: eight harnesses, four live models each, with a prompt that never mentions boxer.

| scenario | result | notes |
| --- | --- | --- |
| `prep` — host-side setup, reached through the harness | **32 of 32** | every harness, every model; 8 of 8 on docker |
| `server` — find this worktree's dev server | **25 of 32** | 5 harnesses on all four models; Kimi and Copilot on two of four; Grok on one |

A harness is blamed only when every model fails it, so Kimi and Copilot passing on two of four is
model adherence. Grok never shows boxer's brief to the model; its cell is left failing so the
finding stays visible.

## Known limits

**PATH shims do not survive a login shell.** A login shell rebuilds `PATH`; on macOS `path_helper`
puts the system directories first. A harness that runs commands through `zsh -lc` — Codex does —
reaches the host. boxer cannot out-rank `path_helper`, so `boxer doctor` detects the situation and
names the enforcement to use instead.

**Gemini CLI needs its own key.** It speaks only the Gemini API, which the AI Gateway does not
serve, so its cells skip rather than run.

**Conductor is verified by hand.** It is a native app rather than an Electron one, so there is no
debugging port to drive, and its CLI drives cloud workspaces where boxer has nothing to sandbox.

**fx is supported inside the guest only.** It has no hooks, its shell cannot be denied headlessly,
and it resolves commands past a PATH shim, so boxer has no way to intercept it from outside. Inside
the guest it passes.

## Reading a run

Archived runs are in `docs/evals/matrix/`, newest first, with a JSON line per run. Two runs are
comparable only when the model, the concurrency and the host match; each report records them.

For a cell below 100%, the scorecard names the claim that failed, and the report keeps the cell's
transcript and trace.
