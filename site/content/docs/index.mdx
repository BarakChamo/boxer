---
title: What is boxer
description: One sandbox per git worktree, so parallel coding agents stop colliding on your machine.
---

boxer gives every git worktree its own sandbox and runs your coding agent's commands in it.

Run three agents on three worktrees and they share one machine. They share one port 3000, one set
of global packages, one home directory and every process left running. boxer moves each worktree's commands
into its own microVM. The agent works as before. It runs `npm test`, and the command runs in that
worktree's sandbox.

```console
$ cd ~/code/myapp-fix-ui   && boxer up
$ cd ~/code/myapp-add-auth && boxer up
$ boxer ls                  # some columns left out
NAME         STATE    BRANCH    SERVES
mild-lynx    running  add-auth  https://add-auth.myapp.localhost:1355
olive-comet  running  fix-ui    https://fix-ui.myapp.localhost:1355
```

Both worktrees run their dev server on port 3000. Each gets its own sandbox and its own URL.

## What you get

- **A sandbox per worktree.** Created on the first command, reused after that, removed when the
  worktree is gone.
- **No change to your agent.** A hook rewrites `npm test` to `boxer run -c 'npm test'` before the
  shell runs it. Exit codes and output come back unchanged.
- **Isolated from your machine.** Each sandbox has its own kernel. It sees the worktree and
  nothing else of your filesystem. On smolvm it reaches only the network hosts you list.
- **Dev servers that do not clash.** Each worktree gets a free host port, and optionally a stable
  `https://<branch>.<repo>.localhost` URL.
- **Low overhead.** A command in a running sandbox takes about 33 ms, close to
  `docker exec`. See [Benchmarks](/docs/evals/benchmarks).

## What is included

| Part | What it does |
| --- | --- |
| `boxer` CLI | Creates sandboxes, runs commands in them, and removes them. One Go binary. |
| Integrations | Hooks, plugins and PATH shims that route an agent's commands. `boxer install` writes them. |
| MCP server | `boxer mcp` gives an agent a `boxer_run` tool. |
| Skill and plugin | Tell an agent how commands run in this repository. They do not enforce anything. |
| Go package and `--json` | Drive sandboxes from your own program. |

The default sandbox is a [smolvm](https://smolmachines.com) microVM. Apple `container`, docker and
podman also work, with less isolation. See [Backends](/docs/backends).

Runs on macOS on Apple Silicon, and Linux on x86-64 or arm64.
