---
title: JSON output
description: The JSON each boxer command prints, its exit codes, and its error shape.
---

`--json` (or `BOXER_OUTPUT=json`) prints exactly one indented JSON document on stdout, with
snake_case fields, on: `ls`, `status`, `down`, `stop`, `rm`, `gc`, `doctor`, `brief`, `tasks`,
`logs`, `backends`, `integrations`, `fork`, `fork ls`, `pack ls` and `capsule inspect`.
`watch --json` prints one object per line ([below](#watching)).

Fields are added, never repurposed or removed.

## `boxer status --json`

```json
{
  "scope": "sb-7e1852e4a3c3",
  "name": "swift-crab",
  "isolation": "worktree",
  "worktree": "/Users/me/src/demo",
  "mount_at": "/workspace",
  "exists": true,
  "state": "running",
  "image": "node:24-bookworm-slim",
  "image_reason": "machine",
  "ports": { "3000": "61234" },
  "urls": { "3000": "https://fix-ui.demo.localhost:1355" },
  "labels": { "boxer.root": "/Users/me/src/demo" },
  "last_used": "2026-09-20T14:31:09Z",
  "last_run": {
    "time": "2026-09-20T14:31:09Z",
    "command": "npm test",
    "task": "test",
    "dir": ".",
    "exit": 1,
    "duration_ms": 8421,
    "git_head": "9f3c1a…",
    "dirty": true,
    "tests": { "tests": 131, "failures": 3, "errors": 0, "skipped": 2, "failed": ["cart/CheckoutTest.applies_discount"] }
  }
}
```

Exit codes: `0` running, `3` stopped, `4` absent, `1` refused.

| Field | Meaning |
| --- | --- |
| `name` | The two-word form of `scope`, derived from it. `--scope` accepts either |
| `ports` | Guest port to the host port it landed on. The only way to find an `auto:` forward |
| `urls` | Guest port to its stable name, when [`[urls]`](/docs/reference/configuration#urls) is on; absent otherwise. Prefer it: it survives restarts |
| `resources` | The [`resources` object](#boxer-ls---json), when the sandbox exists |
| `events` | The last five events for this scope, when the file telemetry sink is on |
| `last_run` | The last command recorded in this scope; what `boxer capsule new` captures. Also carries `scope`, `image`, `pack`, `config_files`, and bounded `stdout_tail` / `stderr_tail` |

## `boxer ls --json`

An array, one object per sandbox:

```json
{
  "scope": "sb-7e1852e4a3c3",
  "name": "swift-crab",
  "state": "running",
  "isolation": "worktree",
  "worktree": "/Users/me/src/demo",
  "integration": "outside",
  "image": "node:24-bookworm-slim",
  "created_at": 1758377469,
  "last_used": "2026-09-20T14:31:09Z",
  "harness": "claude-code",
  "session": "01J9X…",
  "agent": "",
  "backend": "smolvm"
}
```

| Field | Present |
| --- | --- |
| `harness`, `session`, `agent` | When the harness supplied them |
| `backend` | Always; the runtime it lives on, so `ls -A` can mix them |
| `ports`, `urls` | When it forwards ports |
| `git` | Unless `--no-git` |
| `resources` | With `--resources` |

`git` is the state of the worktree the sandbox serves:

```json
"git": { "exists": true, "branch": "fix-ui", "dirty": true, "changed": 3, "ahead": 1, "behind": 0,
         "pr": { "number": 42, "state": "OPEN", "url": "https://github.com/…/pull/42" } }
```

`exists: false` means the worktree is gone and the sandbox is waiting for `gc` or `rm --gone`.
`detached: true` marks a detached `HEAD`. `pr` appears only with `--pr`.

`resources`:

| Field | |
| --- | --- |
| `cpus` | allocated |
| `memory_mib` | allocated |
| `pid` | the machine's process on the host |
| `rss_mib` | actually resident |
| `cpu_percent` | as the host sees it |
| `disk_bytes` | the machine's data directory |
| `measured_all` | false when something could not be read |

A measurement that fails is reported in the row; the command does not fail.

`boxer fork ls --json` prints the same row shape for this scope's children. `boxer fork --json`
prints an array of the new children's names.

## `boxer down|stop|rm --json`

`{ "scope": …, "removed": true|false }`. `down` prints one object; `down --all`,
`down --scope`, `stop` and `rm` print an array, one per sandbox acted on.

## `boxer gc --json`

An array of decisions. A sandbox row is the `ls` row plus `reason`, `deleted` and, on failure,
`error`. A pack row has `pack` (its path), `bytes`, `reason` and `deleted`, and empty sandbox
fields. Under `--dry-run`, `deleted` is `false`.

## `boxer backends --json`

One object per backend: `name`, `configured`, `installed`, `binary`, `version`, `reachable`,
`sandboxes`, `capabilities` (the table `boxer doctor` prints), `problems` (known
misconfigurations, in words), and with `--probe`, `probe: { ok, seconds, error }`. Exit 1 when the
configured backend is missing or not answering, or a probe failed.

## `boxer integrations --json`

One object per integration:

| Field | Values |
| --- | --- |
| `name` | |
| `kind` | `harness`, `orchestrator`, `tool` |
| `cli` | its path, when on `PATH` |
| `project`, `user` | `installed`, `partial`, `no`, `n/a` |
| `skill` | `yes`, `no` |
| `stale` | installed files written by another boxer release |
| `fix` | the command that wires it in |

"Installed" is decided by asking boxer's own installer which files it would write, so this and
`boxer install` agree.

## `boxer brief --json` and `boxer tasks --json`

`brief`: `brief` (the prose), `scope`, `isolation`, `mount_at`, `mode`, `enforcement`,
`intercept`, `passthrough`, `tasks` (name to command line), `task_details` (for table-form tasks),
`ports` (as configured) and `urls` (whether `[urls]` is on).

`tasks`: an array of `{ name, command, description, junit, timeout }`; empty fields are omitted.

## `boxer pack ls --json`

An array of `{ name, path, bytes, saved_at }`.

## `boxer logs --json`

An array of events, in the [event shape](/docs/reference/events#shape).

## `boxer doctor --json`

The resolved configuration and everything boxer checked: `version`, `backend` (capabilities),
`config_files`, `settings` (each `{ key, value, source }`), `scope`, `git`, `image`,
`image_reason`, `sandbox`, `shims`, `signals`, `storage`, `drift` and `warnings`.

`warnings` lists setups that look right and do not hold, such as a login shell that demotes the
shims, or an installed file that has drifted from this binary's copy.

`denied_hosts` appears when the sandbox exists, `network.mode` is `allowlist`, and smolvm recorded a
refused outbound connection or name lookup. Each entry is a host you would add to `allow_hosts`.
Inside the guest a blocked host looks like an ordinary DNS or connect error. `doctor` reports
everything the machine remembers; a failed [run](/docs/guides/troubleshooting) reports only what
was refused during that command.

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | success; for `status`, running |
| 1 | refused or failed |
| 2 | usage error |
| 3 | `status`: the sandbox exists but is stopped |
| 4 | `status`: no sandbox for this scope |
| *n* | `run`: the guest command's own exit code, or 127 when it could not start |

## Errors

A scoped command refused before it can act prints the refusal on stdout and repeats it in prose on
stderr, exiting 1:

```json
{
  "error": {
    "reason": "not inside a git repository",
    "cause": "NO_REPOSITORY",
    "fix": "cd into a git worktree, or `git init`"
  }
}
```

`cause` is a stable identifier; `reason` and `fix` are for people. The object also
carries `scope` (`key`, `name`, `isolation`, `worktree`, `degraded`), empty when no scope was
resolved. The same refusal appears as
prose on stderr, this object under `--json`, and the text of a failed MCP tool call.

| `cause` | When |
| --- | --- |
| `NO_REPOSITORY` | not inside a git repository |
| `WORKTREE_REQUIRED` | `require_worktree = "require"` and this is not a worktree |
| `SCOPE_UNRESOLVED` | the scope could not be determined |
| `NO_SANDBOX` | the command needs a sandbox that does not exist |
| `NO_SUCH_SCOPE` | `--scope` named a sandbox that does not exist |
| `CREATE_FAILED` / `START_FAILED` | the backend refused |
| `PREP_FAILED` | a `prep.commands` line exited non-zero |
| `SETUP_FAILED` | a `setup` or `image_setup` line exited non-zero |
| `HARNESS_INSTALL_FAILED` | inside mode could not install the harness in the guest |
| `NO_SUCH_TASK` | `--task` named a task `boxer.toml` does not declare |
| `NO_SUCH_PACK` | `pack use` named a pack that was never saved |
| `NOT_FORKABLE` | `fork` on a sandbox not prepared with `fork --prepare` |
| `NO_RUN_RECORD` | `capsule new` with no recorded run in this scope |
| `DIRTY_WORKTREE` | `capsule replay` on a worktree with uncommitted changes, without `--allow-dirty` |
| `CAPSULE_DRIFT` | `capsule replay` where `HEAD` differs from the capsule's, without `--allow-drift` |
| `NO_IMAGE` | no image configured and none could be inferred |
| `NO_FREE_PORT` | an `auto:` forward found no free host port |
| `NOT_READY` | `ready` never passed within `ready_timeout` |
| `CONFIG_INVALID` | a key is outside its enumeration, or a value will not parse |
| `TRANSPORT_FAILED` | the connection to the guest dropped mid-command |

## Watching

```sh
boxer watch --json [--interval 1s]
```

One JSON object per line. Two kinds of line share the stream.

A **state change**, found by comparing successive listings:

```json
{
  "time": "2026-09-20T14:31:09Z",
  "change": "created",
  "sandbox": { "scope": "sb-7e1852e4a3c3", "state": "running", "…": "the ls --json shape" }
}
```

`change` is `present` for what existed when the watch started, `created` for a new sandbox, `gone`
for a deleted one, and otherwise the backend's new state (`running`, `stopped`). `sandbox` is the
`ls --json` row without `backend`, `ports`, `git` or `resources`.

An **event**, when the file telemetry sink is on:

```json
{ "time": "2026-09-20T14:31:10Z", "change": "event", "event": { "…": "the event shape" } }
```

`event` is the [event shape](/docs/reference/events#shape), unchanged. With telemetry off, the
stream carries state changes only. Tell the two apart by `sandbox` or `event`, and ignore a line
shape you do not recognise.

`--interval` is how often boxer compares listings; default `1s`. Events are read as they are
written. `watch` runs until interrupted, and exits 1 with a message on stderr if it cannot reach
the backend.

<Callout>
`boxer watch` is not covered by the 1.0 stability promise; the other commands on this page are.
</Callout>
